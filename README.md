# FieldOps API

REST backend for tracking work orders in a small engineering or operations team.

The service implements typed CRUD endpoints, validation, persistent SQL storage, automated tests, Docker packaging, and continuous integration. It also acts as the real API target for the separate [QAForge](https://github.com/CognitiveStrain/qaforge) automation project.

## Stack

- Python 3.12
- FastAPI + Pydantic
- SQLAlchemy + SQLite
- Pytest
- Docker
- GitHub Actions

## Features

- Create, list, filter, update, and delete work orders
- Typed request/response models and input validation
- Status and priority filtering
- Persistent SQL storage
- Health endpoint
- OpenAPI/Swagger documentation generated by FastAPI
- Automated lifecycle and validation tests
- Dockerized runtime
- CI on every push and pull request

## Run locally

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Open `http://127.0.0.1:8000/docs` for the generated OpenAPI interface.

## Test

```bash
pytest -q
```

## Example request

```bash
curl -X POST http://127.0.0.1:8000/work-orders \
  -H "Content-Type: application/json" \
  -d '{"title":"Inspect compressor","priority":"high","assignee":"Kamal"}'
```

## Docker

```bash
docker build -t fieldops-api .
docker run --rm -p 8000:8000 fieldops-api
```
